# Phase 1 — Hướng dẫn từng bước

Mỗi file tương ứng một nhóm trong [../tasks.md](../tasks.md).
Trong file, mỗi task có một mục riêng theo cùng khuôn:

| Mục | Nghĩa là |
|---|---|
| **Mục tiêu** | Xong việc này thì được cái gì |
| **Các bước** | Làm gì, theo thứ tự |
| **Xong khi** | Cách tự kiểm tra là đã xong thật, không phải "chắc là xong" |
| **Bẫy** | Chỗ hay sai, hoặc chỗ sai rồi thì khó sửa |
